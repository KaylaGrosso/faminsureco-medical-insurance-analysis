# FamInsureCo Medical Insurance Case Study

## 📊 Overview
This case study for FamInsureCo explores how various factors like BMI, smoking, age, and geography affect medical insurance charges using descriptive and inferential statistics.

## 🛠️ Tools Used
- Excel
- PowerPoint
- PDF brief for context

## 🔍 Key Insights
- Smoking has the strongest correlation with higher insurance charges (up to 300% increase).
- BMI shows a weak linear trend, with some high-BMI individuals still having lower charges.
- Age and geographic segmentation also highlight cost differences, especially when interacting with smoking status.
